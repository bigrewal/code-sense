# Code-Sense Usage Policy

Before answering a question or starting non-trivial implementation, debugging, architecture, onboarding, or cross-file tasks in this repository, start or refresh the repo mental model with the `code_sense` subagent.

Do not wait idly if initial Code-Sense ingestion takes several minutes. While it runs, continue with normal repo inspection using file reads, search, tests, and Codex tools, then incorporate Code-Sense (get_repo_context) context when it becomes available.

For tiny obvious edits in a known file, Code-Sense is optional.
