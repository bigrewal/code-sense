# Code-Sense Usage Policy

Before answering a question or starting non-trivial implementation, debugging, architecture, onboarding, or cross-file tasks in this repository, use the `code_sense` subagent to build or refresh the repo mental model.

Use Code-Sense context for initial orientation, then use normal file reads, search, tests, and Codex tools for detailed verification and implementation.

For tiny obvious edits in a known file, Code-Sense is optional.
